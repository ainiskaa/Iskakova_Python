# Task 2: Bracket sequence
Given bracket sequence: [((())()(())]] 

  1. Can this sequence be considered correct?
     Answer: No.
  2. If the answer to the previous question is “no”, then what needs to be changed in it to make it correct?
     Answer: In order to make it correct, we need to replace the second-to-last square bracket "]" with the bracket ")".
             So the correct sequence will become: [((())()(()))]
